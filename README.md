# Spawn Rate Scaler
A simple mod for Terraria v1.4.4.9 (via tModLoader) that adds a slider to the Inventory menu. This slider allows you to adjust spawn rates from 0.0x to 20.0x, with preset buttons for min, max, and default spawn rates. The slider menu hides itself when the inventory is closed, and it can be unlocked and moved via the **Lock/Unlock** buttons.
